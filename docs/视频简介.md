# Agent HUD 宣传片 · 发布简介文案

## 主简介（视频简介栏用）

---

Agent HUD —— 一款常驻 Windows 桌面边缘的开源信息工具栏。

它把三件最常看的事固定在屏幕边上：

- **HDR 开关**：双击确认设计，第一下确认、第二下切换，避免误触
- **DeepSeek 余额**：鼠标悬停即展开，API Key 只存 Windows 凭据管理器
- **GLM Coding Plan 额度**：五小时 + 本周双额度圈，自动读取本机 ZCode 登录凭证，零配置

两位角色会随额度状态变换表情；接入 ZCode hooks 后，任务完成会在角色头顶冒气泡提醒，权限请求也可以直接在气泡上点击「允许」，决策原路写回 hook，不用切换窗口。

**其他特性**

- 贴边吸附半隐藏、Home Indicator 拖动、播放全屏内容时自动让位
- 托盘常驻、开机自启、设置页实时预览（黑色毛玻璃 / 白色毛玻璃 / macOS Dock 三款皮肤）
- 命令行接口：`-state` / `-toggle` / `-notify` / `-confirm` 等，方便脚本与程序调用
- 单文件原生 WPF，.NET Framework 4.x 零依赖，免管理员

**安装**：从 Releases 下载 `AgentHUD-Setup.exe`，双击安装（per-user，免管理员），ZCode hooks 自动接入。

**开源地址**：https://github.com/soberkeen/agent-hud
