## 制作说明

- 全片 **85.3s**（5120f@60fps，3840×2160），配音 **GPT-SoVITS v2**（预训练模型零样本，
  女声参考来自 **MeloTTS**（MIT 许可）合成的开源女声），13 句全部进片。
- 音轨 = 女声口播 + Mixkit 电影系音效（滑动/点击/开关/磁吸/riser-impact-sparkle），
  **无 BGM**——要铺 BGM 直接后期加上即可。
- 画面全部由 `tools/promo/remotion` 的 React 代码确定性渲染：HUD 按源码 1:1 复刻，
  时间轴在 `src/spec.ts`，改配音后更新 NARR 表即可全片重排。
