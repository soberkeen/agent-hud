## 制作说明

- 全片 **81.1s**（4865f@60fps，3840×2160）。配音 **GPT-SoVITS v4 预训练**（零样本克隆，
  女声参考 = MeloTTS（MIT）开源女声），默认采样参数（top_k 15 / top_p 1.0 / temp 1.0）
  逐句响度归一 -16 LUFS。
- 音轨 = 女声口播 + Mixkit 电影系音效，无 BGM（后期自铺）。
- 时间轴全自动：`tools/promo/remotion/public/audio/nar/` 换 wav → 跑
  `refs/GPT-SoVITS/gen_timings.py` → `src/spec.ts` 整条时间轴（含音效钉帧）重排。
