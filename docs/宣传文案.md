## 口播技术说明

- 全片 **77.7s**，13 句共约 350 字，平均语速 ≈ 4.5 字/秒（比日常说话略慢，留出音效与呼吸空间）。
- **成片音轨只有圆润版 UI 音效**（滑入/点击/弹出/磁吸），无伴奏、无人声——BGM 和口播直接后期铺上去即可，不用闪避。
- 若需把本文案烧录成字幕：`tools/promo/gen_promo2.py` 里 `SUBS = True` 重渲即可（字幕文本与本表同源）。
