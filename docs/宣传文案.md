## 制作说明

- 全片 **98.4s**（5905f@60fps，3840×2160）。
- 配音 **GPT-SoVITS 洛天依 V1 微调音色**（luotianyi-dub-kit「口语」预设），按 SOP 铁律：
  `--split cut0 --speed 1.1 --seed 42`，采样 5/0.9/0.7；逐句响度归一 -16 LUFS。
- CER 质量闭环（faster-whisper 转写比对）：基线 3 句超标（nar03/06/08），按种子
  [1,7,13,21,42,555,99] 择优后全部达标（0.244 / 0.267 / 0.212）。命名类误识
  （DeepSeek/GLM/ZCode 的字母转写）属 SOP 定义的 ASR 噪声。
- **人耳复核建议**：nar08 开头（约 52.6 – 53.5s）ASR 转写为"哈哈哈"，可能是
  ASR 对"它还"的误听，也可能是合成笑场，建议听一下这句，不行就换 seed 重出。
- 音轨 = 洛天依口播 + Mixkit 电影系音效，无 BGM（后期自铺）。
- 时间轴全自动：`tools/promo/tts/nar_lines.json`（文案）→ 洛天依 kit 合成 →
  `gen_timings.py` 重排 `src/spec.ts` → 渲染。
