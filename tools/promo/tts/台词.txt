下面为大家介绍一款桌面小工具，Agent HUD。它常驻屏幕边缘，把最常用的信息放在随手可见的位置。
它要解决的问题很简单：让重要信息随看随取，不用来回切换窗口。
面板上有三块内容。最上面是 HDR 开关，下面分别是 DeepSeek 余额，和 GLM 的订阅额度。
HDR 采用双击确认的设计。第一下进入确认状态，第二下才会真正切换，可以避免误触。
开启之后，画面的亮度和色彩会有明显提升，区别一目了然。
鼠标放到 DeepSeek 助手上，余额会自动展开；放到 GLM 助手上，五小时和本周两个额度圈同时展开。
单击可以把抽屉固定住，双击则直接启动对应的程序，也就是 ZCode 或者 DSH。
它还接入了 ZCode 的事件通知。任务完成时，角色头顶会弹出气泡来提醒你。
遇到权限请求，直接在气泡上点击允许，决策会写回 hook，任务继续执行，不用切换窗口。
额度的使用状态，也会通过角色表情来呈现。充足时平静，偏低时紧张，耗尽时发呆。
安装很简单，运行安装向导即可完成，ZCode 的 hooks 会自动配置好，程序支持开机自启和系统托盘。
它同时提供命令行接口，一条 notify 命令，就能把消息推送到桌面。
Agent HUD 完全开源，单文件，零依赖。可以在 GitHub 搜索 agent-hud 下载使用。
